AIPartner publishing guide GitHub Pages and Facebook

One branch, one folder, one Save button

Publish the site without getting lost in the file view

You do not publish index.html by selecting it. Confirm that it exists, then leave Code and configure GitHub Pages under the repository Settings.

Do not open index.html

The Code page is only a checkpoint. GitHub Pages publishes the main branch from the repository root. It does not publish one selected file.

AIPartner repository then Settings then Pages then Deploy from a branch

Checkpoint 1

Confirm the entry file, then stop using Code

  1. Open the repository Go to github.com/imtoam/AIPartner.

  2. Look at the first file list Confirm that index.html appears at the top level beside README.md and START_HERE.md.

  3. Do not select the file Its presence is enough. Continue through the Settings tab near the top of the repository.

Checkpoint 2

Turn on GitHub Pages

  1. Select Settings If it is hidden, open the additional repository navigation menu and choose Settings.

  2. Select Pages Find it in the left sidebar under Code and automation.

  3. Choose the source Under Build and deployment, set Source to Deploy from a branch.

  4. Choose the location Select main in the branch menu and /(root) in the folder menu.

  5. Select Save Do not choose GitHub Actions. This static site does not need a custom workflow.

Checkpoint 3

Wait for the live address

Stay on the Pages screen after saving. The first deployment may take several minutes. GitHub will display a message when the site is live.

If something is missing

Use the symptom, not guesswork

Settings is missing

Open the additional repository menu. If it is still absent, confirm that you are signed into the owner account and have administrator permission.

Pages is missing

Look under Code and automation. A private repository may require a paid plan for GitHub Pages. A public repository works with GitHub Free.

The branch menu says None

Open it and select main. If main is absent, the local branch has not been pushed to GitHub.

Save is disabled

The same source may already be saved. Check for main and /(root), then look for the live site message.

The site shows 404

Wait several minutes. Confirm main and /(root), then open Actions and inspect the latest pages build and deployment run.

Only one article fails

Confirm that its file is visible inside introduction on GitHub. Local files are not published until they are committed and pushed.

Facebook

Share the website address, not the repository address

After the selected article opens through github.io, use the matching EN or FR entry in facebook-post.md. Facebook should receive the github.io article URL.
